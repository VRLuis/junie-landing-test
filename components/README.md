# Components

This directory follows the **Atomic Design** methodology for organizing UI components.

## Structure

```
components/
├── atoms/          # Smallest building blocks: buttons, inputs, icons, typography
├── molecules/      # Simple combinations of atoms: search bars, form fields, nav items
├── organisms/      # Complex sections: headers, footers, card lists, sidebars
└── templates/      # Page-level layouts: structure without content
```

See [`skills/ARQUITECTURE.md`](../../skills/ARQUITECTURE.md) for detailed rules on how to compose components at each level.
