# Basic Landing

A personal landing page showcasing my studies in **Artificial Intelligence and Big Data** at [IES Portada Alta](https://iesportada.org) in Málaga, Spain.

## About the Course

I am currently enrolled in the **Specialization Course in Artificial Intelligence and Big Data** (Curso de Especialización en Inteligencia Artificial y Big Data), offered by the Computer Science Department at IES Portada Alta.

This is a **600-hour program** (20 hours/week over 30 weeks) that covers:

| Module | Hours |
|---|---|
| AI Models — search algorithms, evolutionary algorithms, Machine Learning, NLP, tokenization | 90h |
| Machine Learning Systems | 90h |
| AI Programming | 210h |
| Big Data Systems — data storage, extraction, and analysis at scale | 90h |
| Applied Big Data — working with real-world data pipelines and tools | 120h |

The course prepares students to work with large-scale data and intelligent systems — skills used by companies like Amazon, Netflix, and major banks.

## About This Project

This landing page serves as a portfolio and introduction to my journey in AI and Big Data. It is built with:

- **Next.js 16** — React framework for the web
- **React 19** — UI library
- **Tailwind CSS 4** — Utility-first CSS framework
- **TypeScript** — Type-safe JavaScript

## Getting Started

First, install dependencies and run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
